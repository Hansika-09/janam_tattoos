# Janam Tattooz

Official website for **Janam Tattooz** (Janam Tattoo Studio), Bengaluru's premier custom tattoo and sterile piercing studio with locations in **Rajajinagar** (560010) and **Basaveshwar Nagar** (560055).

Rated **5.0 out of 5 stars** across **304 reviews on Google**.

---

## 🌟 Key Features

- **Google Reviews & Ratings**:
  - Prominent 5.0 rating card based on 304 authentic Google reviews.
  - Interactive touch & desktop arrow carousel showcasing verified client review excerpts.
  - "Read All Google Reviews" and "Leave Us a Review" action buttons.
  - Configurable transparent rating configuration.
- **Complete Services**:
  - **Tattoos**: Custom tattoo design, large-scale and full-body tattoos, Polynesian tribal tattoos, cover-ups & reworkings, finishing, touch-ups, aftercare.
  - **Piercings**: Ear piercing (helix, tragus, lobes), eyebrow piercing, nose piercing (nostril, septum), and specialized body piercings.
  - **General Enquiries**: Tattoo appointments, piercing appointments, and design consultations.
  - "Discuss Your Design" WhatsApp integration (`+91 9607452040`).
- **Conversion-Focused Appointment Section**:
  - "Ready For Your Next Piece?" call-to-action matrix.
  - One-click buttons: "Book a Tattoo", "Enquire About Piercing", and "Call the Studio".
  - Dual branch locator cards for Rajajinagar and Basaveshwar Nagar with directions and interactive map embeds.
  - Opening hours reporting & WhatsApp appointment protocols.
- **Visual Portfolio & Lightboxes**:
  - Responsive high-resolution galleries for custom tattoos (`jt1`–`jt5`) and piercings (`jt6`–`jt10`).
  - Fullscreen lightbox viewer with keyboard and touch navigation.
- **Centralized Configuration**:
  - `src/config/business.ts` manages all business details, addresses, ratings, services, and phone numbers in one place.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Deployment**: Vercel ready (`vercel.json`)

---

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

---

## ⚙️ Business Configuration

To update phone numbers, addresses, Google review links, or services, edit:

```typescript
src/config/business.ts
```
